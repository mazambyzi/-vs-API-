Облачная языковая модель работает на серверах провайдера: вы отправляете ей запрос через интернет, а вычисления выполняются удалённо. Это позволяет пользоваться крупными моделями, даже если у вашего компьютера недостаточно ресурсов для их запуска. Скорость и доступность зависят от подключения к сети и условий сервиса. Локальная модель, например запущенная через Ollama, работает на вашем компьютере. После загрузки модели интернет обычно не требуется, а данные можно обрабатывать локально. При этом доступные модели и скорость их работы зависят от памяти и мощности процессора или видеокарты компьютера. Если данные защищены NDA (соглашением о неразглашении), перед отправкой облачному сервису нужно проверить, допускает ли соглашение передачу этих данных стороннему провайдеру.

API — это способ, с помощью которого одна программа обращается к функциям другой программы или сервиса. Например, приложение может отправить модели запрос с инструкцией и текстом для обработки. Сервис принимает запрос, выполняет работу и возвращает ответ, который программа может показать пользователю или использовать дальше. Для доступа к некоторым API требуется ключ — секретная строка, которая связывает запросы с учётной записью или проектом. По ключу сервис может проверять разрешения, применять лимиты и учитывать расходы. Ключ нужно хранить в секрете: не размещать в открытом коде и не отправлять посторонним.
